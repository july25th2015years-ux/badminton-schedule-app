# 🏸 バドミントン練習会 出席カレンダー Webアプリ

バドミントンサークルや練習会の日程調整・出欠確認をスムーズに行うためのWebアプリケーションです。  
参加者はリンクを開くだけで、カレンダーから練習予定を確認し、自分の名前を入力して手軽に出欠（◯ / △）を登録できます。

- 現在のNetlify公開版はローカル保存です。今回の移行内容は各端末の初回表示に入りますが、以降の編集は端末間で同期されません。元サイトの更新も自動では反映されません。
- `npm test` で変換・既存データ保持・一度だけの移行・サンプル退避・不正データ保護を確認できます（Node.js 24）。

## ✨ 主な機能

1. **ログイン不要・手軽な回答**:
   - 参加者はログイン不要で、名前を入力するだけで回答・更新・取り消しが可能。
   - お名前はブラウザに記憶され、2回目以降は自動入力されます。
2. **1か月分の月間カレンダー表示**:
   - 練習予定日と「◯ 参加者数」「△ 条件付き参加者数」が一目で把握できます。
   - 前月・次月・今月の移動に対応。
3. **詳細情報 ＆ Google マップ連携**:
   - 開催時間（開始〜終了時刻）、体育館名、コート面数、備考・会費などを確認可能。
   - 「Google マップで場所を確認」ボタンをタップすると、直接Googleマップが開きます。
4. **「◯」と「△」の出欠管理**:
   - 選択肢は「◯（参加）」と「△（条件付き参加）」の2択（✕は不要）。
   - 「△」を選んだ場合は、参加条件（例:「19:30から遅れて参加」「20:30早退」など）の入力を必須化。
5. **全体出欠マトリクス表（一覧表）**:
   - ヘッダーの切り替えボタンから、参加メンバー×日程の出欠一覧表を表示可能。
6. **共同管理**:
   - 参加者全員が新しい練習日の追加や、既存の日程の編集・削除を行えます。
7. **オフライン・ローカル自動フォールバック ＆ クラウド同期対応**:
   - Firebaseの設定がない場合でも、ブラウザの LocalStorage を利用して手元ですぐに全機能が動作します。
   - Firebase Firestore の設定を投入すると、メンバー全員でのリアルタイム同期が可能になります。

## 🚀 起動方法（ローカル環境）

### 1. 依存ライブラリのインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```
ブラウザで表示されるローカルURL（通常は `http://localhost:5173/`）にアクセスしてください。

### 3. プロダクションビルド
```bash
npm run build
```

## 📲 メンバー全員で共有するためのFirebase設定（無料）

複数人のスマートフォンやPC間でリアルタイムに出欠を共有するには、Googleの無料クラウドデータベース **Firebase Firestore** を連携します。

1. [Firebase Console](https://console.firebase.google.com/) にアクセスし、Googleアカウントでログインして「プロジェクトを追加」します。
2. 左メニュー「ビルド」→「Firestore Database」を選択し、「データベースの作成」をクリックします（テストモードまたは全許可ルールで開始）。
3. プロジェクト設定の「マイアプリ」から「ウェブ（</>）」を追加し、Firebase SDKの設定情報を確認します。
4. プロジェクト直下の `.env.example` をコピーして `.env` を作成し、各値を貼り付けます：
   ```env
   VITE_FIREBASE_API_KEY=AIzaSy...
   VITE_FIREBASE_AUTH_DOMAIN=your-app.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=your-app
   VITE_FIREBASE_STORAGE_BUCKET=your-app.appspot.com
   VITE_FIREBASE_MESSAGING_SENDER_ID=123456789
   VITE_FIREBASE_APP_ID=1:123456789:web:...
   ```
5. これで、誰かが回答したり練習日を追加すると、全員の画面に即座に同期されます！

## 🌐 無料公開（デプロイ）方法

### Vercel / Netlify を利用する場合（おすすめ）
1. コードを GitHub リポジトリにプッシュします。
2. [Vercel](https://vercel.com/) または [Netlify](https://www.netlify.com/) にGitHub連携でプロジェクトをインポートします。
3. 環境変数（Environment Variables）に上記 `.env` の内容を登録してデプロイすれば、全世界でアクセスできる専用URLが即座に発行されます。
